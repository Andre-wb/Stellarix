# Модель шумоподавления — инструкция

## Структура папок

Всё лежит рядом с `model.py`:

```
project/
├── model.py
├── remove_noise_model.pkl      ← создаётся после обучения
└── dataset/
    └── train/
        ├── clean/              ← "чистые" эталонные .wav
        │   ├── sample1.wav
        │   └── sample2.wav
        └── noisy/              ← те же файлы, но с шумом (те же имена!)
            ├── sample1.wav
            └── sample2.wav
```

Важно: файлы в `clean/` и `noisy/` должны называться одинаково — по имени
файла модель ищет пару "чистый / зашумлённый" для обучения и оценки.

## Установка зависимостей

```bash
pip install numpy scipy scikit-learn joblib
```

## 1. Обучение модели

```bash
python model.py train
```

Необязательные параметры:

```bash
python model.py train --max-files 60 --max-test-files 60
```

- `--max-files` — сколько пар файлов из `dataset/train` использовать для обучения (по умолчанию 40).
- `--max-test-files` — сколько файлов взять для расчёта точности сразу после обучения (по умолчанию 40).

После обучения модель сохраняется в `remove_noise_model.pkl` рядом с `model.py`,
и сразу печатается отчёт по качеству (MSE, прирост в дБ, фазовая ошибка).

## 2. Проверка точности уже обученной модели

Если модель уже обучена и просто нужно пересчитать метрики (например, на новом
наборе файлов в `dataset/train`):

```bash
python model.py test
python model.py test --max-files 100
```

## 3. Ручная проверка на одном файле

Прогнать конкретный зашумлённый файл через модель и сохранить результат —
без всякого Rust, просто чтобы послушать результат:

```bash
python model.py denoise path/to/noisy.wav path/to/output_clean.wav
```

## 4. Интеграция с Rust-сервером

Для Rust ничего из перечисленного выше вызывать не нужно — там используется
только одна функция:

```python
from model import process_request

clean_wav_bytes = process_request(noisy_wav_bytes)
```

- На вход — сырые байты WAV-файла (то, что придёт в теле запроса).
- На выход — байты уже очищенного WAV.
- Работа идёт полностью в памяти, файлы на диск не пишутся и не читаются.
- Модель (`remove_noise_model.pkl`) загружается один раз при первом вызове
  и дальше переиспользуется — значит, к моменту первого запроса от Rust
  модель уже должна быть обучена (см. пункт 1).

## Частые ошибки

- **`FileNotFoundError: Модель не найдена`** — модель ещё не обучена.
  Сначала выполните `python model.py train`.
- **`В .../dataset/train/noisy не найдено ни одного .wav файла`** — проверьте,
  что датасет лежит по пути `dataset/train/clean` и `dataset/train/noisy`
  рядом с `model.py`, и что там есть файлы.

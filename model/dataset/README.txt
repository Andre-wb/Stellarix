/clean/  - идеальные сигналы (цель для нейросети)
/noisy/  - зашумленные сигналы (вход для нейросети)

Помехи:
1. Белый шум (SNR: -10..25 дБ)
2. Эхо (задержка: 50-300 мс, затухание: 0.2-0.8)
3. Музыкальный шум (3-8 тонов, амплитуда: 0.1-0.6)

Частота дискретизации: ~16000 Гц
Длина сигнала: примерно 0.3 секунды
Модуляция: FSK (1000 Гц и 2000 Гц)
